Abstract

Decision intelligence is now defined as a superset discipline in which business intelligence is one optional input, yet enterprise transformation programs continue to treat it either as a synonym for analytics or as an unbounded aspiration. This paper proposes a practitioner framework for embedding decision intelligence inside the SAP program context along three load-bearing choices: an AI context-reasoning surface hosted wholly inside the client's DMZ and operated as a durable enterprise capital asset; a program-wide numbering spine anchored on the APQC Process Classification Framework (v7.4) that threads blueprint, technical design, technical object, test plan, dataset, and role and authorisation records through the SAP Activate phase model; and an adoption-first sequencing that moves learning and role design forward in the plan on the evidence that people, not technology, are now the binding constraint on transformation outcomes.

The framework is positioned as additive to the existing SAP toolchain (Cloud ALM, Signavio, Solution Manager, Joule) and to the emerging TM Forum DT4DI stack (IG1307, IG1310, IG1310A, IG1310B, IG1310C), and it makes an explicit break with the systems-integrator-owned platform pattern by naming the sovereign context-reasoning repository as a client-held residual.

The framework in one glance

Three load-bearing choices, each aligned to primary sources:

  • Sovereign context reasoning inside the client's DMZ. The AI reasoning surface that processes program context is a client-owned capital asset, not an SI-owned platform. Compatible with NVIDIA's Secure Agent Workspace and IBM's MCP reference architecture; in explicit tension with IDC's Service Provider Agentic AI Platform.
  • APQC-spined traceability through SAP Activate. The APQC PCF v7.4 provides five-digit stable IDs that thread blueprint → technical design → technical object → test plan → dataset → roles, aligned to SAP Activate's six phases and landed in SAP Signavio Process Manager.
  • Adoption-first sequencing. On Prosci's finding that 63% of AI implementation challenges are human-factor, learning-path assignment and human-authorised decision rehearsal move to Prepare, not Deploy.

Peer-review invitation

The framework is offered as a practitioner argument. Ten specific claims in the paper are ahead of the peer-reviewed literature; the paper names each one and invites review. The four load-bearing claims for reviewers are:

  1. The client-DMZ sovereignty claim.
  2. The APQC-spine traceability claim.
  3. The adoption-first sequencing claim.
  4. The human-authorised decision artifact as the control boundary.
